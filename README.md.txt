# License Plate Detection AI

This project uses **YOLOv8** and **OpenCV** to detect license plates in real-time from a webcam feed.

## Features

- Detect license plates using a trained YOLOv8 model.
- Draw bounding boxes around detected plates.
- Display confidence scores.
- Real-time detection via webcam.

## Requirements

- Python 3.8+
- opencv-python
- ultralytics

Install dependencies with:

```bash
pip install -r requirements.txt
